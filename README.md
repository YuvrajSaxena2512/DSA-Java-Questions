## 🧩 Topics

### Arrays

Contains Java implementations of array-based problems and concepts practiced during CSEP classes.

Topics include:

* Array traversal
* Searching
* Maximum and minimum elements
* Rotation
* Duplicates
* Two-pointer problems
* Basic array algorithms

### Strings

Contains Java solutions for string manipulation and problem-solving.

Topics include:

* String traversal
* Character operations
* String manipulation
* Palindrome problems
* Frequency-based problems
* Basic string algorithms
